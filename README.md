# Doom for the Shanling Q2 (Q2 Pod)

A port of Doom ([doomgeneric](https://github.com/ozkl/doomgeneric)) to the Shanling Q2 running [Q2 Pod](https://github.com/DiamondBond/q2-pod). It runs full screen from **Library → Games**, with the wheel, buttons, touchscreen and sound effects.

## Install

1. Copy the `.doom` folder to the root of the card.
2. Put your own `DOOM1.WAD` in the `.doom` folder. Doom's game data isn't included. You can also use `DOOM.WAD`, `DOOM2.WAD` or `FREEDOOM1.WAD`.
3. Open **Library → Games → Doom**.

## Controls

| Control | In the game | In menus |
| --- | --- | --- |
| Wheel | Turn | Up / down |
| Centre | Fire | Select / yes |
| Return | Menu | Back / no |
| Hold Return | Quit | Quit |
| Play/Pause | Use (doors, switches) | Select |
| Previous | Automap | Back |
| Next | Next weapon | Select |
| Touchscreen | Drag to walk and strafe (further to run); tap to use | Tap to select |
